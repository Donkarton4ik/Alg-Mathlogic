\noindent{\Large \textbf{\subsection{Паттерны}}} \par
\vspace{-20pt}
{\large \textbf{\subsubsection{Шахматные доски}}} \par

Рассмотрим паттерн шахматной доски. Данный паттерн бывает двух видов: с живой и с мертвой клеткой в левом верхнем углу. В каждом из них все четыре соседа каждой клетки имеют цвет, противоположный цвету самой клетки, поэтому используются только две строки таблицы истинности:
\begin{itemize}[itemsep=-3pt]
 \item живая клетка с мертвыми соседями, $f(0,0,1,0,0)=0$ - клетка умирает
 \item мертвая клетка с живыми соседями, $f(1,1,0,1,1)=1$ - клетка оживает
\end{itemize}

На каждом шаге все клетки меняют цвет, а через два шага возвращается в исходное состояние, то есть пара шахматных досок образует цикл периода $2$ шага (рис.\ref{fig:checker}).

Однако цвета чередуются в шахматном порядке только при чётной ширине поля из-за тороидальных граничных условий.
\begin{figure}[H]
 \centering
 \includegraphics[width=\textwidth]{pic/checkerboard.png}
 \caption{Шахматное поле $8\times 8$}
 \label{fig:checker}
\end{figure}

\vspace{-30pt}

{\large \textbf{\subsubsection{Одна живая клетка}}} \par

В отличие от шахматных досок, здесь закрашенные клетки не стоят на месте, а смещаются вправо, закрашивая соседа по диагонали (рис.\ref{fig:drift}). Данный паттерн лежит в основе поведения всех остальных.

На каждом шаге живая клетка исчезает, но одновременно с этим оживают сосед справа и сосед снизу. Эти две новые клетки лежат на одной диагонали, поэтому из одной клетки возникает диагональный отрезок. 

Диагональ в данном случае замыкается при $t=n-1$, при этом состоит из $n$ клеток.

\begin{figure}[H]
 \centering
 \includegraphics[width=\textwidth]{pic/drift.png}
 \caption{Одна клетка на поле $8\times 8$ }
 \label{fig:drift}
\end{figure}

{\large \textbf{\subsubsection{Вертикальная линия из трех клеток}}} \par

От вертикальной линии отходит диагональный хвост, который замыкается в момент $t=7$. При этом, с шага $t=7$ конфигурации поля периодически повторяются (период 8 шагов), двигаясь вправо (рис.\ref{fig:pat_vert}).

\begin{figure}[H]
 \centering
 \includegraphics[width=\textwidth]{pic/pat_vert.png}
 \caption{Вертикальная линия на поле $8\times 8$}
 \label{fig:pat_vert}
\end{figure}

{\large \textbf{\subsubsection{Горизонтальная линия из трех клеток}}} \par

Горизонтальная линия порождает несколько диагоналей, которые накладываются друг на друга. С шага $t=8$ конфигурации поля периодически повторяются (период 8 шагов), двигаясь вправо (рис.\ref{fig:pat_horiz}).

{\large \textbf{\subsubsection{Квадрат $4\times 4$}}} \par

Квадрат разрушается, из его остатков начинают расти диагонали, которые накладываются друг на друга. Однако с шага $t=8$ конфигурации поля периодически повторяются (период 8 шагов), двигаясь вправо (рис.\ref{fig:pat_square}).

\begin{figure}[H]
 \centering

 \caption{Квадрат $4\times 4$ на поле $8\times 8$}
 \label{fig:pat_square}
\end{figure}

{\large \textbf{\subsubsection{Сердечко}}} \par

Для сердечка взято поле $16\times 16$ (см.Рис.\ref{fig:pat_heart}). Исходная форма за один шаг разрушается, оставив лишь часть контура изначальной фигуры. От этого контура начинают расти диагонали, поле заполняется шахматным узором. С шага $t=21$ конфигурации поля периодически повторяются (период 16).

 \caption{Сердечко на поле $16\times 16$}
 \label{fig:pat_heart}
\end{figure}

\noindent{\Large \textbf{\subsection{Классификация по Вольфраму}}} \par

По наблюдаемому поведению автомат следует отнести к классу II, так как из случайного начального состояния он за короткое время переходит к набору периодических структур. Однако данная классификация носит оценочный характер, так как строгих критериев классификации Вольфрама не существует.
