{\Large \textbf{\section{Математическое описание}}} \par
\vspace{-20pt}

{\Large \textbf{\subsection{Конечный автомат}}} \par

Конечным автоматом называется набор
\[
 A = (S, \Sigma, Y, s_0, \delta, \lambda),
\]
где
\begin{itemize}[itemsep=-3pt]
 \item $S$ - конечное множество состояний
 \item $\Sigma$ - конечное множество входных сигналов
 \item $Y$ - конечное множество выходных сигналов
 \item $s_0 \in S$ - начальное состояние
 \item $\delta: S \times \Sigma \to S$ - функция переходов
 \item $\lambda: S \times \Sigma \to Y$ - функция выходов
\end{itemize}

\vspace{-30pt}

{\Large \textbf{\subsection{Клеточный автомат}}} \par

Клеточный автомат - это регулярная решетка одинаковых конечных автоматов (клеток), каждый из которых в момент времени $t$ находится в одном из конечных состояний. Состояние клетки на следующем шаге вычисляется по текущему состоянию клетки и состояниям клеток ее окрестности, причем правило одно и то же для всех клеток. Обновление всех клеток решетки происходит одновременно при переходе с шага t на t+1.

Каждая клетка - автомат $A=(S,\Sigma,Y,s_0,\delta,\lambda)$, где
\begin{itemize}[itemsep=-3pt]
 \item $S=\{0,1\}$ - состояния клетки (0 - мертвая, 1 - живая)
 \item $\Sigma=\{0,1\}^5$ - входной сигнал (набор состояний клеток окрестности фон Неймана и самой клетки)
 \item $Y=\{0,1\}$ - выходной сигнал клетки, ее состояние на шаге $t+1$
 \item $\delta: S\times\Sigma\to S$ - функция переходов, булева функция пяти переменных $f(S_T,S_L,S_C,S_R,S_B)$
 \item $\lambda: S\times\Sigma\to Y$ - функция выходов; выход клетки равен её новому состоянию, поэтому $\lambda=\delta$
 \item $s_0$ - начальное состояние клетки 
\end{itemize}

{\Large \textbf{\subsection{Тороидальные граничные условия}}} \par

Рассматриваются тороидальные граничные условия: поле ширины $n$ замыкается в тор, а индексы клеток берутся по модулю $n$. Тогда соседи клетки $S_{i,j} = S_C$ определяются как
\[
 S_T = S_{(i-1) \bmod n,\, j},\quad S_B = S_{(i+1) \bmod n,\, j},\quad S_L = S_{i,\, (j-1) \bmod n},\quad S_R = S_{i,\, (j+1) \bmod n}.
\]



{\Large \textbf{\subsection{Правило перехода}}} \par

Состояние клетки на шаге $t+1$ вычисляется по состояниям клеток окрестности на шаге $t$:
\[
 S_C^{t+1} = f\bigl(S_T^{t},\, S_L^{t},\, S_C^{t},\, S_R^{t},\, S_B^{t}\bigr).
\]

Окрестность из пяти клеток дает $2^5=32$ возможных конфигураций, а функций $f:\{0,1\}^5\to\{0,1\}$ существует $2^{32}$. Поэтому правило однозначно кодируется 32-битным числом $N$: его двоичная запись, дополненная нулями слева до 32 разрядов, является столбцом значений функции $f$ в таблице истинности, строки которой упорядочены по возрастанию двоичного числа $S_TS_LS_CS_RS_B$ (старший бит - верхний сосед, младший - нижний).

{\Large \textbf{\subsection{Классы Вольфрама}}} \par

Классы Вольфрама - классификация клеточных автоматов, основанная на их поведении. Вольфрам выделил 4 класса:
\begin{itemize}[itemsep=-3pt]
 \item Класс I. После некоторого количества шагов система стабилизируется: все клетки поля переходят в одинаковое состояние.
 \item Класс II. Состояния могут быть различными, однако клетки образуют наборы статичных или периодических простых структур.
 \item Класс III. Образуются сложные структуры, характер взаимодействия которых во многих случаях выглядит хаотическим.
 \item Класс IV. Сложные структуры; очень сложное, порой непредсказуемое (хаотичное) взаимодействие.
\end{itemize}
